# Methodology

F1, F2 y F3 investigan de forma independiente y sólo producen evidencia estructurada.

F4 procesa únicamente ciclos completos de los tres frentes, construye el grafo, mantiene máximo 3 módulos activos y convierte convergencias en especificaciones, artefactos y pruebas.

Regla central: evidencia -> relación -> especificación -> prototipo -> prueba -> resultado.
