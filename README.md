# MAKINA

Cohorte automatizada de investigación, síntesis y desarrollo técnico.

Flujo:

`F1 capacidades actuales + F2 arqueología técnica + F3 mediación físico-informacional -> F4 síntesis/desarrollo`

F1–F3 producen evidencia independiente. F4 puede relacionarla y convertirla en especificaciones, código, prototipos y pruebas, pero nunca dirige las búsquedas de los frentes de investigación.

Estado vivo: `project/state.yaml`
Configuración: `project.config.yaml`
